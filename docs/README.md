# L.o.U.I.S. documentation

The [API reference](https://tenacom.github.io/Louis/) of L.o.U.I.S. is a site, generated from the XML comments of each release.
The site describes the stable release with the highest version, and its [preview part](https://tenacom.github.io/Louis/preview/) describes the release with the highest version, stable or prerelease.
Each line below links the page of a namespace in the preview part, which lists the types of the namespace with the package of each one.

## Namespaces

- [`Louis`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.html): disposables that invoke a callback, utility methods for dates and times, and range checks.
- [`Louis.Collections`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.Collections.html): extension methods for enumerable types.
- [`Louis.ComponentModel`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.ComponentModel.html): type converters between a type and strings, and base classes to write such converters.
- [`Louis.Diagnostics`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.Diagnostics.html): types to create, inspect, and rethrow exceptions, to identify critical errors, and to perform self-checks.
- [`Louis.Fluency`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.Fluency.html): extension methods that embed conditional logic and other operations in a fluent call chain.
- [`Louis.Hosting`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.Hosting.html): types that run an `AsyncService` as a hosted service, in the `Louis.Hosting` package.
- [`Louis.IO`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.IO.html): types to read and write text files.
- [`Louis.Processes`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.Processes.html): types that run a child process and read what it writes, utility members for the console, and, in the `Louis.Testing` package, a test double of `IProcessRunner`.
- [`Louis.Text`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.Text.html): C# string literals, Unicode and UTF-8 utilities, text editing utilities, and conditional interpolated string handlers.
- [`Louis.Threading`](https://tenacom.github.io/Louis/preview/api/namespaces/Louis.Threading.html): a base class for long-running services, thread-safe flags and references, and utility methods for `ValueTask`.
