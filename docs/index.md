L.o.U.I.S. (Lots of Useful and Interesting Stuff) is a collection of types commonly needed in the development of .NET libraries and applications.
It is pronounced _LOO-iss_, like the name Louis.

The API reference describes every type of the packages listed below.
A member that only some target frameworks have shows its target frameworks.

This site has two parts.
The [stable part](https://tenacom.github.io/Louis/) describes the stable release with the highest version.
The [preview part](https://tenacom.github.io/Louis/preview/) describes the release with the highest version, stable or prerelease.

The source code, the issue tracker, and the releases are on [GitHub](https://github.com/Tenacom/Louis).
The [changelog](https://github.com/Tenacom/Louis/blob/main/CHANGELOG.md) lists the changes of each release.
